# VolleyServe.it

**strumenti aperti al servizio della pallavolo**

**open tools built to serve volleyball.**\

[🇮🇹 Italiano](#-italiano) · [🇬🇧 English](#-english)

---

## 🇮🇹 Italiano

**VolleyServe.it** è una raccolta di strumenti, applicazioni ed esperimenti che ho realizzato per la pallavolo.

Il nome nasce da un gioco di parole: **al volley serve IT** - Information Technology - ma anche dall'inglese *serve*, il servizio nella pallavolo e, nel mondo web, l'azione di mettere a disposizione applicazioni e contenuti.

VolleyServe.it nasce dall'incontro tra pallavolo, software, dati e sperimentazione.

---

## 🇬🇧 English

**VolleyServe.it** is a collection of tools, applications and experiments I have built for volleyball.

The name is a play on words. In Italian, **“al volley serve IT”** means *volleyball needs IT — Information Technology*. In English, *serve* is both a fundamental volleyball action and, on the web, the act of delivering applications and content.

VolleyServe.it is where volleyball, software, data and experimentation meet.
